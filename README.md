# Registration Form

A simple registration form built with HTML and CSS.

## Features
- Clean and modern UI
- Responsive design
- Simple user registration layout

## Files
- `index.html` – page structure
- `style.css` – form styling

## How to view
1. Open `index.html` in your browser.
2. Or deploy the files on any static hosting platform.

## Description
This project contains a frontend registration form with fields for:
- First name
- Last name
- Email
- Password
- Confirm password
